Command Conventions

Repository paths in this document use forward slashes where practical because they work naturally on Linux and macOS and are also accepted by Python on Windows.

Where a command shows:

python

Linux and macOS systems may use:

python3

depending on how Python is installed.

Commands that create or remove temporary files are shown separately for Windows Command Prompt and POSIX shells where the syntax differs.

39. Exact Canonical-Byte Verification

A redirected CLI bundle normally contains a trailing newline, so it may pass semantic reconstruction while failing strict canonical-byte verification.

The distinction is:

semantic reconstruction != exact canonical-byte identity


Windows Command Prompt

Create an exact canonical-byte bundle:

python -c "import importlib.util,pathlib; p=r'demo/ORL_Money_Reference_Kernel_v2_1_0.py'; s=importlib.util.spec_from_file_location('orl',p); m=importlib.util.module_from_spec(s); s.loader.exec_module(m); b=m.scenario_bundle('two-node')[1]; pathlib.Path(r'%TEMP%\ORL_Money_two_node_v2_1_0_canonical.json').write_text(m.canonical_json(b),encoding='utf-8')"

Verify it:

python verifier/ORL_Money_Independent_Verifier_v2_1_0.py --bundle "%TEMP%\ORL_Money_two_node_v2_1_0_canonical.json" --strict-canonical

41. Verifier Exit Codes

The command-line verifier uses:

0 = verification or self-test PASS
1 = verification, corpus, data, intake, or file-access FAIL
2 = command-line usage error or missing mode

Missing files, unreadable files, invalid UTF-8, malformed JSON, duplicate JSON keys, canonicalization failures, and verification mismatches return exit code 1.

Exit code 2 is reserved for command-line usage errors, such as invoking the verifier without selecting a supported verification mode.

43. Scope

These commands verify the declared ORL-Money v2.1.0 bounded reference behavior.

They do not establish:

- truth of source observations
- account ownership
- authorization
- payment execution
- clearing
- settlement
- legal finality
- complete fraud prevention
- universal financial correctness
- production security
